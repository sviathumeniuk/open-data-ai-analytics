# Опис даних

## Загальна інформація

**Назва:** Відомості з Реєстру платників податку на додану вартість  
**Станом на:** 28 серпня 2019 року  
**Формат:** CSV
**Кількість записів:** ~281 077

Набір даних містить інформацію про всіх зареєстрованих платників ПДВ в Україні, включаючи назви підприємств, їхні ідентифікаційні коди, дати реєстрації та виключення з реєстру.

## Джерело

**Офіційне джерело:** Портал відкритих даних України  
**Посилання:** https://data.gov.ua/dataset/db391c93-1e68-43c9-bd85-7c6a8427b114  
**Постачальник даних:** Державна податкова служба України

## Структура даних (Data Dictionary)

| Колонка      | Тип    | Опис                                                                   |
| ------------ | ------ | ---------------------------------------------------------------------- |
| `name`       | string | Повна назва платника ПДВ (юридичної особи або підприємця)              |
| `kod_pdv`    | string | Індивідуальний податковий номер (ІПН) платника ПДВ                     |
| `dat_reestr` | date   | Дата включення до Реєстру платників ПДВ (формат: DD.MM.YYYY)           |
| `dat_term`   | date   | Дата виключення з Реєстру платників ПДВ ("null" якщо платник активний) |

### Особливості даних

- **Кодування:** UTF-8 з BOM
- **Роздільник:** крапка з комою (`;`)
- **Відсутні значення:** позначені як `"null"` (у лапках)
- **Формат дат:** DD.MM.YYYY (наприклад, 01.06.2011)
