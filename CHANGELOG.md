# Changelog

Усі значущі зміни в цьому проекті будуть задокументовані в цьому файлі.

Формат базується на [Keep a Changelog](https://keepachangelog.com/uk/1.0.0/),
та цей проект дотримується [Semantic Versioning](https://semver.org/lang/uk/).

## [0.1.1] - 2026-02-15

### Added

- `src/analysis.py` - модуль з функціями аналізу гіпотез:
  - `analyze_seasonality()` - аналіз сезонності реєстрацій
  - `analyze_legal_forms()` - аналіз організаційно-правових форм
  - `analyze_economic_impact()` - аналіз економічного впливу
- `src/data_processing.py` - модуль для роботи з даними:
  - `load_data()` - завантаження CSV файлу
  - `process_data()` - обробка та очищення даних
  - `load_and_process_data()` - комбінована функція
- `src/visualizations.py` - модуль з функціями візуалізації:
  - `plot_registrations_by_year()` - графік реєстрацій за роками
  - `plot_seasonality()` - графіки сезонності
  - `plot_legal_forms()` - графіки організаційно-правових форм
  - `plot_economic_impact()` - графіки економічного впливу
- `src/config.py` - централізована конфігурація проекту

### Changed

- Рефакторинг ноутбука `00_eda_template.ipynb`:
  - Винесено бізнес-логіку в модулі `src/`
  - Спрощено код комірок за рахунок використання функцій
  - Покращено читабельність та структуру аналізу

### Fixed

- Поділ відповідальності між завантаженням та обробкою даних
- Виправлено помилку в підрахунку організаційно-правових форм підприємств

## [0.1.0] - 2026-02-14

### Added

- Початкова структура проекту з директоріями `data/`, `notebooks/`, `src/`, `reports/`
- README.md з описом проекту, мети, джерела даних та 5 гіпотез для аналізу
- data/README.md з детальним описом структури даних реєстру платників ПДВ
- Завантажено вихідні дані: `pdv_actual_28-08-2019.csv` (~281,077 записів)
- Jupyter notebook `00_eda_template.ipynb` для первинного аналізу даних
- Базова конфігурація для аналізу
- Завантаження та парсинг CSV даних з обробкою кодування UTF-8 BOM
- Перетворення дат у формат datetime з обробкою помилок

### Implemented

- **Гіпотеза 1: Сезонність реєстрацій**
  - Аналіз розподілу реєстрацій платників ПДВ за місяцями та кварталами
  - Візуалізація помісячного та поквартального розподілу
  - Перевірка наявності піків на початку кварталів

- **Гіпотеза 2: Зміна популярності організаційно-правових форм**
  - Функція класифікації підприємств за організаційно-правовою формою
  - Аналіз динаміки популярності форм за роками
  - Порівняння періодів до 2010 та після 2010 року
  - Візуалізація зміни популярності ПП vs ТОВ

- **Гіпотеза 3: Вплив економічних подій**
  - Порівняльний аналіз періодів 2010-2013 та після 2014 року
  - Розрахунок середньої кількості реєстрацій на рік для кожного періоду
  - Визначення відсоткової зміни активності реєстрації
  - Візуалізація динаміки з виділенням ключових періодів

- Базова візуалізація розподілу реєстрацій за роками
- Перевірка структури даних, типів полів та пропущених значень

### Technical

- Налаштування стилю графіків
- Обробка некоректних рядків при завантаженні CSV
- Заміна текстового "null" на pandas NA для коректної обробки
- Конфігурація pandas для відображення всіх колонок
